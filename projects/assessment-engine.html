01 / PROBLEM

The problem
space.

Automated assessment can be expensive and opaque when every answer is sent to a large language model, while instructors still need a review path.

02 / APPROACH

How I
approached it.

The engine uses lightweight vector similarity and rubric logic, then routes uncertain submissions to an instructor queue instead of forcing every answer through an automatic decision.
